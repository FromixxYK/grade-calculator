# Grade Calculator for Teachers

A simple console program for teachers. The teacher types a student's name and 5 scores, and the program shows the average and the grade. At the end it shows how many students were entered and the class average.

## Requirements
- The program shall ask for a student's name and then exactly 5 scores.
- The program shall accept only whole numbers from 0 to 100 and, for any other value, show an error message and ask for the same score again.
- The program shall calculate the student's average and show it with 1 decimal place.
- The program shall show the grade using the scale A = 90–100, B = 75–89.99, C = 60–74.99, F = below 60.
- The program shall keep asking for new students until the user types "end", and then show the number of students and the class average.

## Grading scale
| Grade | Average |
|-------|---------|
| A | 90 - 100 |
| B | 75 - 89.99 |
| C | 60 - 74.99 |
| F | below 60 |

## How to run
1. Open https://www.onlinegdb.com and choose C++.
2. Paste the code from main.cpp and click Run.
